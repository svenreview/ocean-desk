# Ocean Desk 2.0 — 32차 오늘의 집중 요약

## 목적
갤러리 상단에서 **오늘 완료한 집중 시간**, **완료 세션 수**, **다음 여행 티켓까지 남은 테스트 퍼즐 수**를 쉽게 확인합니다.

## 구현
- 브라우저에서 완료된 25분/50분 세션만 `od-local-daily-focus-v1`의 `records` 배열에 저장합니다.
- 하루 구분은 사용자의 브라우저 로컬 날짜 `YYYY-MM-DD`를 사용합니다.
- 세션 ID 중복은 1회만 집계하고 최근 400건까지만 보존합니다.
- 중간에 일시정지·재설정한 시간은 완주 세션으로 집계하지 않습니다. 기존 전체 누적 집중 시간은 유지합니다.
- 여행 티켓까지 남은 퍼즐 수는 **10 - 현재 퍼즐 잔액**으로 표기하며, 테스트 보상·티켓 지갑은 기존 로직을 변경하지 않습니다.
- 서버 계정의 지갑 화면에서는 퍼즐 잔여 개수는 서버 조회 값으로 표시하고 오늘 집중 시간/세션 수는 집계하지 않습니다. 서버의 집중 내역은 별도 계정 화면에서 확인하도록 안내합니다.
- 로컬 세션 기록은 서버 계정의 기록이나 지급 자산으로 전송되지 않습니다.

## 테스트
1. 25분+50분 완료 → 75분, 2회. 동일 세션 중복 이벤트로 이중 집계하지 않음. 새로고침 후 유지.
2. 로컬 퍼즐 1개 획득 → 다음 티켓까지 9조각 표시.
3. 서버 컬렉션 7조각 조회 시 3조각 표시 및 로컬 집중 숫자를 숨김. 서버 모드에서 발생한 데모 완료는 로컬 기록에 추가되지 않음.
4. 다른 날짜의 완료 기록은 오늘 합계에 반영하지 않고 유효하지 않은 집중 시간도 제외.

## 범위
개발 브랜치 `feature/bali-gallery-focus`에만 반영. 운영 Vercel, GitHub `main`, Supabase 운영 DB 변경 없음. 실제 Google OAuth·기기 간 동기화/서버 집중 기록 검증은 아직 미완료입니다.
