# OCEAN DESK 2.0 — 35차 PC·모바일 실사용 테스트 및 Preview 출시 전 점검

작성 기준: 2026-11-05 (KST) · 작업 브랜치: `feature/bali-gallery-focus` · PR: https://github.com/svenreview/ocean-desk/pull/1

## 현재 상태 및 제한 사항
- 자동 브라우저 회귀 테스트(34차까지 37개), 단위 및 PostgreSQL 권한 통합 테스트는 통과했지만 **실제 Android/iOS·데스크톱 사용자의 수동 검증을 대체하지 않습니다**.
- GitHub의 Vercel 상태 검사는 마지막 확인 시 `failure`이었고, 연결된 주소가 `upgradeToPro=build-rate-limit` 안내로 이어졌습니다. **정상 Preview URL이 확인되지 않았으므로 공개 접속 링크가 있다고 안내하지 않습니다**.
- Vercel 배포, 유료 플랜 업그레이드, 운영 사이트 연결, Supabase DB 변경은 하지 않았습니다.
- Google OAuth 실계정/기기간 동기화는 비활성화 상태입니다. 로그인·실제 서버 보상·광고 검증은 이 테스트의 성공 기준에 넣지 않습니다.
- 현재 로컬 보상은 화면 시뮬레이션입니다. 실제 가치나 자동지급을 보장하지 않습니다.

## A. 무료 로컬 Preview — 개발자 PC에서 실행
```bash
git clone https://github.com/svenreview/ocean-desk.git
cd ocean-desk
git checkout feature/bali-gallery-focus
node scripts/ocean-preview-readiness.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```
PC의 동일 브라우저에서 `http://127.0.0.1:4173/` 접속. 준비 검사 결과의 `ok:true`를 확인합니다.

### 휴대전화 실기기 테스트 (비공개 Wi-Fi에서만)
- 개발 PC와 휴대전화를 동일한 **신뢰할 수 있는 로컬 Wi-Fi**에 연결합니다.
- 다른 기기에서 접속해야 하는 경우 서버를 종료한 다음 `python3 -m http.server 4173 --bind 0.0.0.0`으로 실행하고 PC의 **사설 LAN IP**를 확인합니다. 휴대전화 브라우저는 `http://<PC-사설-IP>:4173/`로 접속합니다.
- 방화벽 포트를 외부 인터넷으로 공개하거나 공유기 포트포워딩을 하지 않습니다. 테스트 후 서버를 종료합니다.
- HTTP 사설 LAN 주소는 일부 브라우저의 보안 기능/오디오 정책을 제한할 수 있습니다. 이를 Google OAuth 검증 환경으로 사용하지 않습니다.
- 같은 PC의 `localhost`와 휴대전화의 `http://<PC-IP>`는 **서로 다른 브라우저 저장 공간**입니다. 집중 시간·퍼즐 진행이 동기화되지 않는 것이 현재 정상입니다.
- Windows 환경은 `py -m http.server 4173 --bind 127.0.0.1` 또는 `py -m http.server 4173 --bind 0.0.0.0` 명령을 사용합니다. 설치된 Python 실행명에 따라 다를 수 있습니다.

## B. 자동 사전점검
`node scripts/ocean-preview-readiness.mjs`가 확인하는 것:
- 필수 HTML·일러스트·계정 어댑터·런타임 설정·Vercel 파일 존재
- HTML의 주요 스크립트 연결
- 계정, Google OAuth, 서버 집중, 지갑 자동 초기화의 기본 비활성화
- 브라우저 설정에 의심스러운 비밀 키 기입 여부(패턴 기반 기본 검사, 정식 비밀 스캔을 대체하지 않음)
- `vercel.json` JSON 파싱 가능 여부
- **배포·API 통신·DB 작업은 수행하지 않습니다.**

GitHub Actions에서 위 사전검사, 관련 단위 테스트 및 Chromium 브라우저 검사를 자동 실행합니다.

## C. 실제 사용 점검표
아래는 **수동으로 확인해야 하는 항목**입니다. 자동 테스트 성공을 수동 테스트 완료로 표시하지 않습니다.

| ID | 기기/동작 | 완료 조건 |
|---|---|---|
| P01 | PC Chrome / 초기 접속 | 카페 화면이 비정상 공백 없이 표시되고 콘솔 치명 오류 없음 |
| P02 | Android Chrome / 360px 전후 | 가로 스크롤, 버튼 겹침, 다이얼로그 잘림 없음 |
| P03 | iPhone Safari / 세로·가로 전환 | 화면 폭, 하단 안전 영역, 글자 크기 정상 |
| P04 | 갤러리 9개 공간 | 전체/획득/잠금 필터 및 각 공간 사진형 일러스트와 지역명이 맞음 |
| P05 | 세계지도 · 여행 티켓 | 로컬 테스트 티켓 잔액이 0이면 탐험 차단, 새 공간 획득 후 바로 보기 연결 |
| P06 | 25분 → 50분 변경 | 이미 집중한 시간은 사라지지 않고 시간 변경만으로 퍼즐을 지급하지 않음 |
| P07 | 집중 일시정지·이어하기 | 타이머가 중복 진행되지 않으며 정상 복원 |
| P08 | 파도 소리 On/Off | 사용자 조작 후 소리가 제어되며 예상치 못한 자동 재생 없음 |
| P09 | 모바일 조작 메뉴 접기 | 집중 타이머·배경은 유지, 메뉴 펼치기 가능 |
| P10 | 조명 기본/따뜻하게/은은하게 | 색조 변경 및 새로고침 후 선택 유지 |
| P11 | 25/50분 집중 완료 | 완료 세션은 날짜당 올바르게 기록, 동일 완료 중복 없음 |
| P12 | 오늘/최근 7일 통계 | 주간 집계·3/7/14일 배지·목표 100/150/300/600분 반영 |
| P13 | 로컬 보상 | 완료 이벤트에만 테스트 퍼즐 청구, 한 세션 중복 지급 방지 |
| P14 | PC와 휴대전화 기록 비교 | 로컬 기록은 기기별 별도. 서버 동기화되는 것처럼 보이지 않음 |
| P15 | 네트워크 차단 시 화면 | 내부 SVG 풍경과 로컬 타이머 화면이 표시되는지 확인; 외부 자원 의존성 별도 기록 |
| P16 | 시스템 움직임 줄이기 | 조명·풍경 전환 애니메이션 감소 및 버튼 작동 |
| P17 | 탭 전환·화면 잠금·앱 전환 후 복귀 | 집중 경과 시간/타이머 표시가 예상대로 갱신되는지 육안 확인 |
| P18 | 개인정보·모드 구분 | 운영 로그인 비활성화, 테스트 퍼즐과 실제 서버 자산의 차이를 명시 |

## E. 정식 Preview 확인 조건
1. Vercel 빌드 제한·실패 원인을 대시보드에서 확인하고 **무료 한도 안에서 해결 가능한지 확인**합니다.
2. 기존 Vercel 프로젝트의 `feature/bali-gallery-focus`에 연결된 Preview 배포가 성공하고 고유 HTTPS URL이 실제로 열리는지 검증합니다.
3. Preview의 공개 자산/런타임 설정이 운영용 비밀 키를 노출하지 않는지 확인합니다.
4. PC·Android·iPhone 실기기 점검 결과와 차단 결함 조치 상태를 기록합니다.
5. 운영 사이트 및 `main` 머지는 대표님의 명시적인 승인 이후에만 진행합니다.

> 현재 단계는 **Preview 준비 및 테스트 계획**입니다. 배포·실기기 수동 테스트·실 OAuth 연동이 완료되었다는 의미가 아닙니다.
