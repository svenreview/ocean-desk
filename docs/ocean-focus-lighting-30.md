# Ocean Desk 2.0 — 30차 조명·집중 화면 안정화

## 변경 사항
- 집중 화면의 조명을 **기본 → 따뜻하게 → 은은하게 → 기본** 순서로 전환하는 버튼을 추가했습니다.
- 조명은 풍경 위의 정적 오버레이에서 처리합니다. 기존 뽀모도로 시작·중단·시간 설정과 파도 소리 동작은 변경하지 않습니다.
- 조명 선택은 브라우저에 `od-light-preference-v1`로 저장하고 새로고침 후에도 유지합니다.
- 조명 강도 변경은 어두운 필터 및 따뜻한 색조로 구현하여 원본 9개 SVG 풍경을 수정하거나 외부 이미지를 호출하지 않습니다.
- 기기의 `prefers-reduced-motion: reduce` 설정에서는 풍경과 조명의 CSS 전환 애니메이션을 끕니다.
- 모바일 360px 화면에서 조명 버튼의 터치·화면 경계를 테스트합니다.

## 회귀 검증
- 조명 3단계 순환, 접근성 라벨, 새로고침 후 설정 복원.
- 조명 변경 전후 타이머 실행 여부·선택 시간·파도 소리 상태 불변.
- 모바일 기기의 움직임 감소 설정에서 전환 시간 0초 및 조명·일시정지 버튼 조작.
- 기존 24개 브라우저 검사, 인증·설정 단위 검사 및 임시 PostgreSQL 통합 검사 함께 실행.

## 운영 분리
- 기존 GitHub `feature/bali-gallery-focus` 브랜치만 변경.
- Vercel 공개 사이트, GitHub `main`, Supabase 운영 DB 미변경. Google OAuth 실제 연동 및 기기 간 서버 동기화는 여전히 미검증.
