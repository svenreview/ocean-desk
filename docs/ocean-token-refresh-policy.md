# Ocean Desk 2.0 — 22차: 토큰 갱신과 계정 전환 안전성

**상태:** Draft PR에서 구현·검증 중. 실제 Google OAuth 및 운영 배포 미완료.

## 문제와 개선
Google 로그인 중 Supabase Auth의 `TOKEN_REFRESHED` 이벤트는 정상적으로 동일 사용자 토큰을 갱신하는 과정입니다. 이를 로그아웃처럼 처리하면 `od-focus-sync.js`가 현재 서버 집중 세션을 취소된 것으로 오해할 수 있습니다.

- **동일 계정의 토큰 갱신:** 기존 집중 세션 연결과 화면의 사용자 데이터 유지, 최신 서버 데이터 재조회.
- **로그아웃 또는 다른 계정 로그인:** 기존 계정 컬렉션 화면 즉시 폐기, 복구 후보/집중 세션 메모리 초기화.
- 비동기 `getUser()` 결과가 뒤늦게 도착하더라도 이전 계정의 상태가 화면에 나타나지 않도록 세대 검사 유지.
- 계정 구분 기준은 OAuth 이메일 표시가 아니라 Supabase Auth의 `user.id` 값.

## 신규 테스트
`tests/auth-account.spec.mjs`에서 같은 계정의 `TOKEN_REFRESHED`는 로그아웃 이벤트를 내보내지 않는지, 다른 계정 토큰으로 바뀔 때는 화면 초기화 이벤트를 내보내고 새 계정 데이터가 표시되는지 검사합니다.

## 미검증
- 실제 Google OAuth 동의 및 리디렉션
- 실제 모바일/PC 여러 기기 토큰 갱신과 네트워크 단절
- 실제 Supabase 운영 환경에서의 세션 복원과 서버 지갑 조회

운영 Supabase DB와 Vercel 공개 사이트는 변경하지 않았습니다.
