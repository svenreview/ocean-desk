# Ocean Desk 2.0 — 33차 최근 7일 집중 통계

## 추가 기능
- 갤러리의 '오늘의 집중' 아래 **최근 7일 집중** 통계를 추가했습니다.
- 7개 날짜별 완료 집중 시간(분)을 막대 그래프로 표시하고, 최근 7일 총 시간/완료 세션 수를 합산합니다.
- **연속 집중 일수**는 완료한 날짜를 중복 없이 계산합니다. 오늘 완료가 있으면 오늘부터, 아직 오늘 완료가 없다면 어제부터 역순으로 계산합니다. 하루라도 빠지면 연속 기록은 종료됩니다.
- 로컬 날짜는 `new Date(연, 월, 일, 12시)`로 이동하여 일광절약시간제(DST) 경계에서 24시간 단순 차감으로 발생할 수 있는 오류를 줄입니다.
- 기존 `od-local-daily-focus-v1` 기록 형식과 세션 완료/퍼즐 지급 로직을 유지합니다.
- 25/50분 완료 세션만 통계에 집계하고 세션 ID가 중복되면 1회만 반영합니다.
- 서버 컬렉션 조회 시 **로컬 주간 통계와 연속 일수는 숨기고**, 서버 계정 화면에서 기록을 확인하도록 안내합니다.

## 자동 테스트
- 최근 7일 150분·4회, 연속 3일, 날짜별 차트 7개 및 중복 세션 집계 방지.
- 오늘 집중하지 않았을 때 어제부터 연속 일수를 계산하고, 오늘 완료 시 연속 일수 증가.
- 서버 컬렉션의 로컬 기록 격리, 로그아웃 시 복원, 360px 모바일 화면 넘침 여부.

## 제외 범위
- 실제 Google OAuth 서버 집중 기록 기반 주간 통계 및 PC/휴대전화 동기화는 아직 미검증입니다.
- 로컬 집중 기록은 브라우저 저장소에만 있으므로 다른 기기와 자동 공유되지 않습니다.
- 운영 Vercel 사이트, Supabase 운영 DB, GitHub `main`은 변경하지 않았습니다.
