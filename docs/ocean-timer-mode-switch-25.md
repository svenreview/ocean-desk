# Ocean Desk 2.0 — 25차: 집중 시간 전환 시 누락 방지

## 이번 변경
- 기존 뽀모도로 25분·50분·자유집중 타이머의 **시간 설정 전환** 도중 누적 시간 일부가 사라질 수 있는 문제 수정.
- 진행 중 타이머에서 다른 시간으로 변경 시 기존 시간을 일시정지 처리하고 실제 경과 초를 누적 집중 시간에 저장.
- 이미 일시정지한 상태에서 다른 시간으로 변경해도 경과 시간이 정확히 한 번만 누적됨.
- 같은 시간 설정 버튼을 다시 누를 때는 불필요하게 누적 시간을 재기록하지 않음.
- 중간에 시간을 바꾼 것만으로 퍼즐·티켓을 지급하지 않음.
- 서버 집중 기능이 활성화된 환경에서는 모드 변경을 `pause`/ `reset` 이벤트로 전달해 이전 시도에 대한 서버 증빙을 완료로 처리하지 않음.

## 브라우저 회귀 검사
- 진행 중 25분에서 50분으로 전환한 경우: 경과 92초 보존, 새 시간 50:00, 보상 창 미표시
- 일시정지 후 시간 변경: 경과 63초 1회 누적, 같은 시간 재선택 시 중복 누적 없음
- 기존 모바일·갤러리·파도 소리·지도·로컬 보상 테스트 함께 실행

## 범위
모든 코드는 `feature/bali-gallery-focus` 개발 브랜치에만 반영합니다. Vercel 공개 사이트, GitHub main, Supabase 운영 DB 및 OAuth 설정을 변경하지 않았습니다.

주의: 로컬 집중 시간 누적은 클라이언트 편의 기록입니다. 실제 퍼즐 지급의 신뢰 가능한 근거로 사용하지 않습니다.
