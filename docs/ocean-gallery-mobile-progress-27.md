# Ocean Desk 2.0 — 27차: 모바일 갤러리 및 지역 수집 현황

## 이번 변경
- 갤러리에 **전체 · 획득 · 잠금** 필터 추가. 각 필터의 표시 개수와 현재 선택 상태를 안내합니다.
- 모바일 화면에서도 필터 버튼을 쉽게 터치할 수 있도록 버튼 높이·그리드 배치를 조정했습니다.
- 세계지도 지역 카드에 **획득 n/전체 m** 표기와 수집 진행 막대(비율)를 추가했습니다.
- 접근성을 위해 필터/공간의 `aria-pressed`, 지역 버튼의 수집 설명 `aria-label`을 연결했습니다.
- 획득한 공간만 선택 가능하고, 잠긴 공간은 비활성 상태를 유지합니다.
- 서버 로그인 계정의 읽기 전용 상태, 로컬 테스트 티켓·퍼즐의 분리 정책은 그대로 유지합니다.

## 26차 회귀 오류 수정
지난 26차에서는 지도에서 새 방으로 이동하는 이벤트가 지도 HTML 생성보다 먼저 연결되어 갤러리 초기화가 중단되는 문제가 있었습니다. 지도 HTML이 준비된 후 이벤트를 등록하도록 옮겼습니다.

## 검증
- 모바일 전체/획득/잠금 필터 전환과 보유 공간 개수 검증
- 제주 지역 1개 보유 → 수집 진행 1/3 → 티켓 추첨 후 2/3
- 새 공간 바로 보기, 퍼즐·티켓, 25/50분 타이머 및 Google 계정 모의 인증에 대한 브라우저 회귀
- 서버 보상/집중 세션/권한 검증은 별도 임시 PostgreSQL 환경에서 확인

**주의:** 실제 Google OAuth·기기 간 동기화 및 운영 서버 보상 연동은 미구현/미검증. GitHub feature 브랜치만 변경했고 운영 Supabase/Vercel/main은 변경하지 않았습니다.
