# Ocean Desk 2.0 — 29차 풍경 품질 및 오프라인 일러스트

## 변경 사항
- 총 9개 공간(발리 3, 제주 3, 산토리니 3)의 개별 풍경을 **원본 SVG 일러스트**로 제작하여 렌더링합니다.
- 일출/노을/야경, 숲/비, 제주 해안, 산토리니 흰 건물, 발리 야자수 등 지역별 형태와 색상 차이를 반영합니다.
- 모든 일러스트는 `od-scenery.js` 내 정적 SVG 생성 코드로 제공하며 **외부 이미지 CDN 요청이 필요 없습니다**.
- 갤러리 미리보기, 획득 공간 목록 썸네일, 실제 집중 화면의 배경을 동일한 공간 ID 기준으로 통일했습니다.
- 25/50분 뽀모도로와 파도 소리, 인증·보상·계정별 수집 기능을 변경하지 않았습니다.
- 기존 기본 CSS에 남아 있던 외부 Unsplash 사진 주소 2개도 제거했습니다. 정상 동작 시 외부 이미지 서버 접속이 필요하지 않습니다.

## 검증
- 9개 공간 ID 모두 SVG data URL 생성, 각 공간이 구별되는지 및 외부 이미지 URL이 사용되지 않는지 검사.
- 모바일 390px에서 제주 숲속서재 → 발리 선셋룸을 전환할 때 미리보기·집중 화면 이미지가 일치하는지 검사.
- 모드 전환 후 집중 타이머 상태·파도 소리 설정 유지 검사.
- 기존 갤러리·지도·퍼즐/티켓·로그인 모의 및 서버 거래 테스트 동시 실행.

## 제한사항
- 본 일러스트는 실제 풍경 사진이나 정확한 현지 지형을 재현하는 지도가 아닙니다.
- 정식 사진으로 대체하려면 이미지 사용 허가와 상업적 이용 조건을 별도로 확인해야 합니다.
- 실제 Google OAuth 및 Supabase 운영 연동, 모바일/PC 기기 간 동기화는 아직 미검증입니다.
- 변경은 `feature/bali-gallery-focus`에만 반영합니다. 운영 Vercel, Supabase DB, `main`은 수정하지 않았습니다.
