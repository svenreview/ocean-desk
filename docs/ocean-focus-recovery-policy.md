# Ocean Desk 2.0 — 집중 기록 복구 정책 (스테이징 초안)

## 현재 원칙
- 로그인 식별: Supabase Auth 사용자 ID. 브라우저에서 보낸 사용자 ID는 불신.
- 중단된 서버 집중 기록은 사용자별로 조회하는 **명시적 복구 방식**. 자동 복구 또는 자동 보상 없음.
- 서버 기준 시각으로 남은 시간을 계산. 휴대전화 시각이나 LocalStorage 완료 신호는 서버 보상 검증에 사용하지 않음.
- **다른 기기**에서 같은 Google 계정으로 접속할 때도 활성 서버 세션 조회 가능하도록 설계.
- 바다/산/자연 콘텐츠 테마는 동일 계정의 컬렉션을 공유하며, 현재는 바다 MVP 중심.
- 기존 로컬 뽀모도로·파도 소리 기능 보존. 서버 연동 비활성 기본값.

## 사용자 흐름
1. OAuth 승인 및 계정/서버 집중 설정을 켠 스테이징에서 같은 Google 계정으로 로그인합니다.
2. 공부 공간에 들어가면 기존 타이머가 작동합니다.
3. 계정 메뉴의 **서버 집중 찾기**를 눌러 본인의 활성 집중 세션을 조회합니다.
4. 남은 시간이 있으면 **이어하기**를 직접 선택합니다.
5. 복구 직전에 서버에 남은 시간을 재확인하고, 기존 타이머의 남은 시간을 맞춥니다.
6. 서버 시간이 이미 25/50분을 충족하면 **완료 확인**을 요청합니다. 집중 완료만으로 퍼즐이 생기지는 않습니다.

## 안전 제한
- 복구 진행 시 미완료 LocalStorage 보상은 서버로 합산하지 않음.
- 휴식/일시정지/초기화에서 기존 서버 세션 취소 정책 유지. 취소된 세션은 퍼즐 지급 증빙 불가.
- 다른 사람이 가진 세션 ID를 브라우저에서 전송해도 서버가 사용자 ID를 검증함.
- 서버 진행 시간이 2시간을 넘으면 만료로 간주. 만료 세션은 보상 증빙 생성 불가.
- 계정 로그아웃/변경 시 클라이언트의 복구 후보와 메모리상의 서버 세션 식별자 초기화.
- 서버와 오디오/타이머 화면은 별도 기능. 서버 오류 발생해도 로컬 타이머 사용 가능.
- **벽시계 경과는 사용자가 실시간으로 공부했음을 보장하지 않습니다.** 실제 집중 품질을 측정하는 기능은 미구현.
- 별도 인증된 광고 제공사 콜백이 없으므로 정식 보상 적립은 미활성화.

## 현재 테스트와 미완료
- 임시 PostgreSQL 테스트: 사용자별 조회, 남은 시간, 25분 완료 가능, 만료·비로그인/타 사용자 접근 제한.
- 브라우저 자동 테스트: 공간 입장 전 복구 거부, 갤러리 자동 타이머에 명시적 복구 허용, 원래 타이머 표시 갱신.
- **실제 Google OAuth 로그인·Supabase Edge Function 배포·2대의 실기기 전환·네트워크 끊김 중 서버 복구 실측은 아직 미완료.**
- 서버 저장 기능을 켜기 전 OAuth 설정, URL 허용 목록, 보안/동시 요청/복구 순서 통합검증 필요.

관련 파일: `docs/ocean-server-focus-status-draft.sql`, `supabase/functions/od-focus-session/index.ts`, `od-focus-sync.js`.
