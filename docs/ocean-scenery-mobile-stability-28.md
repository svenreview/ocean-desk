# Ocean Desk 2.0 — 28차 풍경 전환·모바일 집중 화면 안정화

## 확인된 문제
- 기존에는 발리·제주 등 특정 풍경에서 '풍경 보기/독서/집중'으로 화면 모드를 전환하면 안내 문구가 기본 산토리니 문구로 되돌아갔습니다.
- 좁은 모바일 화면은 우측 조작 패널·집중 타이머·하단 시점 제어 버튼이 화면을 벗어나지 않는지 점검할 필요가 있었습니다.

## 이번 변경
- 선택한 공부 공간의 `id/name/desc`를 화면 모드 전체에서 일관되게 사용하도록 유지합니다.
- 선택한 풍경의 `aria-label`도 공간 이름으로 업데이트합니다.
- 공부 공간에서 나올 때 선택한 공간의 임시 UI 상태를 정리합니다.
- 모바일 폭 740px 이하에서 사이드 패널의 최대 높이·스크롤·타이머 HUD 너비·하단 시점 제어 너비를 제한합니다.
- 420px 이하 초소형 화면의 패널 그리드와 버튼 높이를 조정합니다.
- 기존 타이머/파도 소리 로직 및 서버 계정 데이터는 수정하지 않았습니다.

## 신규 브라우저 테스트
- 잠금 해제된 제주 숲속서재를 선택하고 풍경 보기 → 독서 → 집중 모드를 전환해도 제주 설명 및 타이머 동작 상태가 보존되는지 검증
- 모바일 360×740에서 패널/타이머/시점 제어의 좌우 경계 및 타이머 일시정지·파도 소리 토글을 검증

## 배포 및 인증 원칙
- 테스트 완료 전 운영 배포 없음. GitHub `main`, Vercel 운영 사이트, Supabase 운영 DB 미변경.
- 실제 Google OAuth 및 PC·휴대전화 계정 기록 동기화는 아직 별도 실환경 검증이 필요합니다.
- 새로운 계정·프로젝트 생성 없이 기존 개발 브랜치만 사용합니다.
