# Ocean Desk 2.0 — 31차 모바일 집중 조작 메뉴 접기

## 이번 변경
- 화면 폭 740px 이하에서 화면 상단에 **조작 메뉴 접기/펼치기** 버튼을 표시합니다.
- 메뉴를 접으면 하단 조작 패널을 숨기고, 풍경과 집중 시계 및 하단 시점 버튼을 남깁니다.
- 버튼의 `aria-expanded`와 `aria-controls`를 동기화하여 보조기기에서도 접힌 상태를 확인할 수 있습니다.
- 메뉴를 접거나 펼칠 때 타이머 진행 상태, 선택한 집중 시간, 파도 소리, 풍경 ID, 조명 설정이 변하지 않도록 독립적인 UI 상태로 처리합니다.
- 집중 화면을 다시 열면 조작 메뉴가 열린 기본 상태로 복귀합니다.
- PC에서는 접기 버튼을 숨기고 기존 측면 메뉴를 유지합니다.

## 자동 검증
- 30차 조명 기능: Chromium 26/26 및 서버 거래/RLS 테스트 통과 확인.
- 31차 신규 회귀 검사 2개: 모바일 360px에서 메뉴 접고 펼치기, 조작/타이머/파도 유지; 다시 입장한 모바일 UI의 기본 상태 및 데스크톱 동작 확인.
- 기존 브라우저·지갑·권한/보상 관련 자동 테스트와 함께 실행합니다.

작업은 GitHub `feature/bali-gallery-focus` 브랜치에서만 진행했습니다. 운영 Vercel 사이트, Supabase 데이터베이스, `main`은 그대로 유지합니다. 실제 Google 로그인/기기 간 동기화는 여전히 실환경 검증이 필요합니다.
