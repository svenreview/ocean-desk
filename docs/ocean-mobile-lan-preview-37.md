# Ocean Desk 2.0 — 37차 모바일 LAN 미리보기 테스트

## 이번에 실제 구현한 것
- `ocean-local-server.py`: Python 표준 라이브러리만 사용하는 로컬 테스트 서버.
- 기본 실행은 `127.0.0.1:4173` 바인딩(PC 본인만 접근 가능).
- `--lan` 옵션을 사용자가 명시적으로 선택할 때만 `0.0.0.0:4173` 바인딩(같은 신뢰할 수 있는 네트워크 내 다른 기기가 접근할 수 있음). 일부 사설 IPv4 후보를 표시하지만 **방화벽·VPN·무선 AP 격리 설정에 따라 실제로 연결되지 않을 수 있음**.
- 브라우저 캐시 대신 최신 개발 파일을 확인할 수 있도록 `Cache-Control: no-store` 적용.
- GitHub Actions 로컬 미리보기 ZIP에 실행 파일·안내문 포함. Vercel에 추가 배포하지 않음.
- 자동 점검: 번들 파일 9개 포함, LAN 실행 안내 포함, Python 문법 검사, 기존 인증·보상·브라우저 회귀 검사.

## PC에서 실행
1. [GitHub Actions](https://github.com/svenreview/ocean-desk/actions/workflows/ocean-desk-smoke.yml)에서 최신 성공 실행의 `ocean-desk-local-preview` 아티팩트를 받습니다.
2. GitHub에서 받은 ZIP을 풀고, 안에 있는 `ocean-desk-local-preview.zip`을 다시 풀어 둡니다.
3. 압축을 푼 폴더에서 터미널을 열어 아래 실행.
   - Windows: `py ocean-local-server.py`
   - macOS/Linux: `python3 ocean-local-server.py`
4. PC 브라우저에서 `http://127.0.0.1:4173/` 접속.

## 휴대전화에서 접속 (권한을 이해한 후 선택)
1. PC와 휴대전화를 **같은 신뢰할 수 있는 사설 Wi-Fi**에 연결합니다. 공공 Wi-Fi 사용 금지.
2. 기존 PC 서버를 Ctrl+C로 종료합니다.
3. 아래 명령으로 LAN 모드에서 재실행합니다.
   - Windows: `py ocean-local-server.py --lan`
   - macOS/Linux: `python3 ocean-local-server.py --lan`
4. 터미널에 표시되는 *후보* URL 중 PC의 실제 Wi-Fi 사설 IP와 일치하는 주소로 휴대전화에서 접속합니다. (예: `http://192.168.x.x:4173/`; 이는 형식 예시이며 실제 IP가 아닙니다.)
5. 휴대전화에서 연결되지 않으면 PC 방화벽 또는 공유기의 기기 간 통신 차단을 확인합니다. **인터넷 포트포워딩, 공개 터널, 원격 노출로 해결하지 않습니다.**
6. 테스트 후 Ctrl+C로 서버를 종료하고, 필요한 경우 방화벽 예외도 해제합니다.

## 미리보기 실사용 점검 항목
- 모바일 화면 가로 넘침 없음, 갤러리 및 세계지도 팝업 조작 가능.
- 발리/제주/산토리니의 9개 일러스트 전환, 조명 3종, 파도 소리, 25/50분 뽀모도로 상태 확인.
- 집중 타이머 일시정지·재개·초기화·완료 보상 흐름, 중간 시간 변경 시 누적 기록 보존.
- 하루/7일 완료 통계, 목표 100/150/300/600분 및 3/7/14일 성취 배지.
- 모바일 조작 메뉴 접기·펼치기, 세로/가로 회전, 잠금 화면·다른 앱 전환 후 복귀, 터치 버튼 크기.
- PC와 모바일은 **각자의 로컬 저장소를 사용하므로 기록이 동기화되지 않는 것이 현재 정상입니다**.

## 보안 및 검증 범위
- HTTP LAN 주소는 **보안 연결(HTTPS)이 아니며**, 이 미리보기에서는 실제 계정 로그인·민감정보 입력·광고 보상 지급 테스트를 하지 않습니다.
- GitHub/Vercel/Supabase 운영 서비스와 데이터베이스를 변경하지 않았습니다.
- 이번 작업은 개발 브랜치 코드와 GitHub CI에서 실행되는 자동 테스트입니다. 실제 Android/iOS 기기에서 직접 실행했다고 주장하지 않습니다.
- Vercel 무료 배포 한도 초과 문제는 별도로 남아 있으며, 로컬 미리보기는 이를 우회하는 테스트 수단입니다.
