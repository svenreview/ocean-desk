# Ocean Desk 2.0 — 34차 주간 목표 및 연속 집중 배지

## 새로운 기능
- 주간 목표 100·150·300·600분 중 선택. 선택값은 브라우저 로컬 저장소 `od-weekly-goal-v1`에 기록되어 새로고침 후에도 유지됩니다.
- 최근 7일 동안 완주한 25분/50분 세션 합계로 목표 달성률(최대 100% 진행 막대)과 달성 상태를 계산합니다.
- 연속 집중 3일/7일/14일을 달성하면 해당 성취 배지가 잠금 해제된 모양으로 표시됩니다.
- 배지는 화면상의 동기부여 요소일 뿐입니다. 기존 퍼즐·여행 티켓·광고 보상 정책을 변경하지 않으며 새로운 보상을 지급하지 않습니다.
- 서버 계정의 컬렉션 조회 모드에서는 로컬 목표 및 연속 집중 배지 영역을 숨깁니다. 계정 전환이 로컬 목표 설정을 변경하지 않습니다.

## 회귀 테스트
- 세션 150분 완료 후 기본 150분 목표 달성, 300분으로 변경 시 50% 표시, 새로고침 후 설정 유지.
- 연속 14일 완료 기록에서 3/7/14일 배지 3개 활성화. 테스트 지갑 자산 지급/변경 없음.
- 서버 계정 조회 중 로컬 배지/목표 가림, 로컬 데모로 복귀 후 설정 복원.

## 범위와 한계
- 로컬 테스트 기록만 사용합니다. 실제 Google OAuth 서버 저장과 기기 간 동기화는 아직 검증 전입니다.
- 별도 계정, Supabase 프로젝트, 유료 서비스 생성 없음.
- 변경은 GitHub `feature/bali-gallery-focus` 개발 브랜치에만 적용. `main`, Vercel 공개 사이트 및 Supabase 운영 DB는 변경하지 않았습니다.
