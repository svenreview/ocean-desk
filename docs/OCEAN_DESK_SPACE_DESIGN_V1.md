# OCEAN DESK — 공간 설계안 v1
확정 방향: 단일 오션뷰 집중 카페 브랜드 아래 테마관 3개 + 개인 집중실. 기존 '오션뷰 도서관'은 독립관에서 제외하고 2관 스터디 카페 테마로 통합.

## 브랜드
OCEAN DESK — 바다에서 쉬고 나만의 시간에 집중하다.
원칙: 바다가 주인공, 건물은 서로 다른 디자인 언어, 체험 우선·UI 최소화, 좌석 관당 8석. 한 장면에 두 상자형 건물을 복제하지 않는다.

## 사용자 여정
1. 초기 입장: 바다를 정면에 보는 해안 산책로 / 중앙 광장.
2. 광장의 낮은 석재 안내판: [1관 산토리니 카페] [2관 오션뷰 스터디 카페] [3관 선셋 라운지] [개인 집중실].
3. 목적지 클릭 또는 안내판 선택 → 해당 관으로 카메라 전환, 이후 아바타 동선/출입구 연계.
4. 좌석 클릭 → 자리 시점 → 타이머·파도소리 ON/OFF.
5. 뒤로가기 → 광장. 모바일에는 관 선택 단축 버튼 제공.
6. 음악 플레이리스트는 후순위. 공식 유튜브 임베드와 권리/정책 검토 후 연결.

## 공간 마스터플랜
- 진입 광장: 해안 절벽과 바다, 아이보리 석재 보행로, 꽃과 초목, 낮은 조형물. 3갈래 동선을 명확히.
- 1관 좌측 해안 노출형. 카페 실내 4석 + 그늘 테라스 4석. 직접 바다 정면.
- 2관 우측 안쪽 조용한 스터디 카페. 원목 서가, 천장 높이, 개인 책상 8석, 창으로 간접 바다뷰.
- 3관 광장 아래쪽 별도 석양 테라스. 8석, 앉는 방향과 조명으로 1관과 확실히 구분.
- 개인 집중실: 1인용 인스턴스. 좌석 경쟁 없음. 선택 즉시 독립된 바다 전망 공간.
- 추가 동시접속: 8석짜리 방 인스턴스를 늘리는 구조. 실제 확장은 운영 성능과 Realtime 동시접속을 확인한 뒤.

## 인터랙션 기준
- 안내판·메뉴 양쪽 모두 클릭 가능. UI 라벨은 한국어 우선.
- 3D 카메라 이동은 0.7~1.2초 부드럽게. 장면 전환 중 재입력 방지.
- 파도소리는 사용자 클릭 후 재생(브라우저 자동재생 정책 대응), 음량/음소거 기억.
- 25분/50분/자유 집중 타이머.
- 카메라 접근성: 건너뛰기, 멀미 줄이기, 저사양 모드, 2D 공간 선택 대체 경로.
- 모바일 최적화: 손쉬운 관 선택, 프레임 제한, 저비용 그림자/텍스처 LOD.
- 3D 씬과 정보형 홈페이지는 분리하여 검색/애드센스 품질 유지.

## 개발 마일스톤
A. 1관 + 광장 대표 장면을 고품질 GLB 모델/텍스처로 시각 검증.
B. 세 공간 각각 완전히 다른 실내를 만들고, 모든 관 8석 배치.
C. UI·사운드·이동·타이머.
D. DB 리팩터링: rooms 템플릿(cafe,study)을 themed rooms(1,2,3)로 확장; 기존 데이터를 무조건 삭제하지 않음. instances/instance_seats와 좌석 번호 유지.
E. Supabase Auth, RLS, Realtime Presence 및 점유 정책을 개발/검증한 후 공개.
F. Vercel 배포, wellnesscome.com DNS 전환, 콘텐츠/애드센스 심사 대비.

## 현재 상태
기존 프로토타입은 두 관(카페/스터디) 8석씩, 시각 프로토타입. 신규 3관·개인 집중실·실시간 동기화는 아직 구현 전. 이 문서는 기획 기준이며 운영 DB/프로덕션 화면을 직접 변경하지 않음.
