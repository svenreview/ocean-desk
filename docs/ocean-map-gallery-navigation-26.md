# Ocean Desk 2.0 — 26차 세계지도에서 새 공간 바로 이동

## 변경 사항
- 세계지도에서 테스트 여행 티켓으로 새 공간을 획득하면 획득 공간으로 바로 이동하는 버튼 표시.
- 버튼 클릭 시 세계지도를 닫고 갤러리를 열어 방금 획득한 공간을 선택.
- 지도를 다시 열면 이전 추첨 메시지와 버튼을 초기화하여 오해를 방지.
- 서버 계정은 기존과 동일하게 읽기 전용이고, 실제 서버 여행 티켓의 브라우저 직접 사용은 금지.

## 검증
- 새 공간 획득 후 갤러리에 직접 이동, 갤러리 선택 상태, 이전 추첨 메시지 초기화, 로컬 보유 공간 저장 보존.
- 서버 계정에서 지도 추첨 및 새 공간 이동 버튼 차단.
- 기존 뽀모도로, 25/50분 변경, 파도 소리, 로컬 퍼즐, 계정 보안 회귀 테스트와 함께 CI 검증.

## 다음
- 지역 선택/수집 현황 가독성 개선 및 모바일 갤러리 탐색.
- 실제 Google OAuth 및 다른 기기 저장 동기화는 별도 승인된 테스트 환경이 필요하며, 운영 DB는 변경하지 않음.

**운영 환경:** 기존 GitHub 계정 유지, 개발 브랜치만 변경. 공개 Vercel, Supabase 운영 DB 및 `main` 미변경.
